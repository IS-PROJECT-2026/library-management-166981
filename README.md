## About

A responsive web-based library management system for managing books and members with real-time search and data persistence.

## Features

- Book catalog management (add, delete, borrow/return)
- Member registration and tracking
- Real-time book search
- Dashboard statistics
- LocalStorage data persistence
- Responsive design for all devices

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage API
- GitHub Pages
